# 🍽️ Restaurant Website Project
This is a responsive restaurant website built using HTML, CSS, and basic JavaScript. It showcases a modern food menu, a gallery, and contact information.

### 🌟 Features:
- **Responsive Design:** Works perfectly on mobile and desktop.
- **Menu Gallery:** Beautifully displayed food items.
- **Modern UI:** Clean and professional layout for better user experience.

### 🛠️ Tech Stack:
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript

### 🎯 Goal:
Created this project to practice web layout design and CSS responsiveness as part of my Outreachy 2026 preparation journey.
